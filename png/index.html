and the dropdown itself, one click opening a branch

what was actually broken

The dropdown was fine all along — one click opened a branch, double click picked the item, and the session recorded it. The pick was simply never read by the priority tree. It was stored on the session and nothing outside that module ever looked at it, which is exactly why it felt like it "moves over but connects nothing".

The tree now filters using the session's own membership list, so there is one definition of "what is in this session" rather than a second one that could drift. A session that is only a branch, with nothing picked, leaves the tree alone — same as before.
