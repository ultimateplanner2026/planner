why the planner could not stop this itself

The page already carries no-cache tags. They have never done anything: GitHub sends cache-control: max-age=600 as a real HTTP header, and a header always beats a tag in the page. So the browser is entitled to keep an old copy. The planner cannot change that header — but it can notice and tell you.
