Both of your symptoms are one bug. The planner listens to the cloud so changes arrive without a refresh — and that listener can die without saying so. The fix stops guessing: it compares the version this device last applied against the version the cloud actually holds. If the cloud is ahead and the listener has not said so, the listener has missed something — rebuild it and take the change.
