You asked to see the wording, so the AFTER picture is the wording.

First, what the arrow actually does — I read the code rather than guessing, because it decides how the message should read. Outdenting moves the item up one level and takes everything inside it along. Nothing is deleted, and the → arrow puts it back. So the dialog must not look like a danger warning — a red "are you sure?" for a reversible move trains you to click through every dialog, including the ones that matter.

What the wording does:
• asks a plain question in the title — "Move this out to its own branch?"
• names the item and its parent, so you know which row you hit
• shows the move as now → after, rather than describing it
• says what travels with it — anything inside moves too
• says it is reversible, naming the → that undoes it
• the confirm button says Move it out, not "OK" — the button names the action, so it reads correctly if you skim.
