Why. The code that handles a drop writes the date onto the one thing you dragged and stops there. Nothing walks down into the branch, so the activities inside it keep whatever date they had — usually none. The branch looks like it moved; the work inside it did not.

What the fix does. Dropping a branch carries its activities with it: everything inside gets the same day, so the whole group lands together. One exception kept deliberately — an activity with its own repeat rule keeps that rule rather than being pinned to the dropped day, which is the same protection that already stops a weekly routine being re-anchored when you move one occurrence.
