Remove the demo data from your planner

Five branches that a bad build planted between 26 September and 4 October.

Why the last page did nothing — measured, not guessed.

Your planner syncs through Firebase. Deleting from this page only touched the copy in this browser, and the next sync merged the cloud copy straight back. The removal has to happen inside the planner itself, so it is saved and synced like any edit you make.

It also missed Family: the list of demo branches was built with a pattern that required a space in the name, so the one-word branch was never on it.
What will be removed — these five top-level branches and everything inside them, plus the demo habits and routines:
  1. Riverside Clinic
  2. Maple Street house
  3. Harborview LLC
  4. Family
  5. Study - MSc

Anything you created is kept — including your own tasks that sit inside one of these, which are moved up rather than deleted. A branch of yours that happens to share a name with something further down the demo tree (Kitchen, Garden, Admin) is not touched: only these five exact top-level names are matched.

How to run it
  1. Open your planner: https://ultimateplanner2026.github.io/planner/
  2. Wait for it to finish loading and signing in.
  3. Open the browser console — on a Mac, Option + Command + J in Chrome, or Option + Command + C in Safari after enabling the Develop menu.
  4. Copy everything in the box below and paste it at the console prompt, then press Enter.
  5. It prints what it found and removed, saves, and the page refreshes itself.
